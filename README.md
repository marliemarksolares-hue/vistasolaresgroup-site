# Vista-Solares Group website

Plain static site (no build step). Hosted on GitHub Pages at https://www.vistasolaresgroup.com

- Pages: index, firm, services, resources, calculator, contact (.html)
- site-config.js: paste the Apps Script web-app URL into VSG_FORM_URL to deliver contact-form messages to a Google Sheet and email
- dc-lite.js: small template runtime used by the calculator, calendar, tabs and form
- CNAME: custom domain for GitHub Pages
